Time to change things:

- `mkdir gear` makes a folder called `gear`.
- `touch gear/tent.txt` makes an empty file (or updates the time on an existing one).
- `rm junk.txt` deletes a file. There is no bin: it's gone.
- `rmdir empty-folder` deletes an empty folder.

Paths like `gear/tent.txt` mean "the file `tent.txt` inside the folder `gear`".

Tip: press **Tab** while typing a name and the shell completes it for you.
