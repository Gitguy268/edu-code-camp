This is real Python, running in your browser. In Python you show things with `print`:

```python
print("Good morning, camp!")
```

Like in most languages, text goes in quotes. Python doesn't care whether you use `"double"` or `'single'` quotes, as long as both ends match.

`print` can take several values. It puts a space between them:

```python
print("I have", 3, "tents")   # I have 3 tents
```
