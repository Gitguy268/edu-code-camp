Programs talk to you through **output**. In JavaScript the simplest way to show something is `console.log`:

```js
console.log("Good morning, camp!");
```

Whatever is between the brackets gets printed in the **Output** window. Text has to be inside quotes, so JavaScript knows where it starts and ends. Text in quotes is called a **string**.

You can print more than one line by calling `console.log` again:

```js
console.log("Line one");
console.log("Line two");
```

## Your task

Print exactly this line:

```
Hello, edu-code-camp!
```

Press **Run** to try your code as often as you like. When you think it's right, press **Submit**. Hidden checks will look at what you printed.
